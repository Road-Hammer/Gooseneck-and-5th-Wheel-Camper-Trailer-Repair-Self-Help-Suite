# Using the Offline Shop CMMS (Service Log + Vendors)

This suite is not only a repair book — it is a lightweight **CMMS / repair-shop tracker** that runs offline.

## Pieces

| Piece | What it is |
|-------|------------|
| **Assets (rigs)** | Each trailer/camper you own or maintain |
| **Work orders** | Open, in progress, waiting parts, completed |
| **Service log** | History that proves care and teaches the next generation |
| **Vendors** | Shops and mobile techs you trust |
| **Guide links** | Vendors appear on the repair guide they specialize in |

## Typical flow

1. **Add asset** — name, type (including equine / stock / cattle), VIN.  
2. **Add vendor** — phone, trade, mark preferred if you want them first.  
3. **Link vendor** to a guide (e.g. breakaway switch) or category (brakes).  
4. When something breaks: open a **work order**, attach asset + vendor + guide.  
5. Log labor hours, parts cost, invoice ref.  
6. Set status to **completed** when done.

## Why this matters offline

Cell service dies in the same places trailers break. Your history and phone numbers need to live **on the machine**, not only in a cloud app.

## Family legacy tip

Export or copy the `data/stwl_camper.db` file to USB when you can. That file is the shop’s memory.
